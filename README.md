# Personal portfolio

A responsive, dependency-free portfolio built with HTML, CSS, and JavaScript.

## Make it yours

1. Open `script.js` and replace the sample content in the `portfolio` object.
2. Replace project `url` values with links to live demos or repositories.
3. The résumé link points to the redacted `CV - no phone.pdf`.
4. Preview locally by opening `index.html`, or serve it with any static web server.

## Deploy

This site can be hosted for free on GitHub Pages, Cloudflare Pages, Netlify, or
Vercel. Once deployed, each provider supports connecting a custom domain.
